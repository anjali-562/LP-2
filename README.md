# Cloud, DevOps & Web Technologies Lab

A collection of practical implementations and mini-projects covering Web Development, Cloud Computing, DevOps, Deployment, APIs, Virtualization, and Database Operations.

This repository contains hands-on experiments and deployment practices using technologies such as Angular, Docker, Apache, MongoDB, Node.js, Google Cloud Platform (GCP), AWS EC2, AJAX, jQuery, Salesforce, and more.

### 1. AJAX

### 3. Apache2

### 4. Docker
Containerization concepts using Docker including image creation and deployment.

### 5. EC2 with Given Template
AWS EC2 deployment setup using predefined templates for hosting applications.

### 6. File Transfer
File transfer implementation and server communication practices.

### 7. Google Cloud SDK + Hello World App
Google Cloud SDK setup and deployment of a basic application.

### 8. GitHub Practical
Git and GitHub version control operations including repository management and collaboration.

### 9. jQuery
Frontend development and DOM manipulation using jQuery.

### 10. MongoDB CRUD API
REST API implementation using MongoDB for Create, Read, Update, and Delete operations.
